CRED-CASA — COMO TESTAR

1) Abra um terminal na pasta backend.
2) Rode:
   npm.cmd install
   npm.cmd run local:all

3) Abra no navegador:
   http://localhost:3000/teste-api.html

4) Teste os três cenários:
   - APROVADO: Score -> Decisão -> integracaoJuros -> Operações -> FINALIZADO
   - REPROVADO: Score -> Decisão -> encerra
   - ANÁLISE MANUAL: Score -> Decisão -> PENDENTE_ANALISE_MANUAL

INTEGRAÇÃO REAL NA FACULDADE

No backend/.env configure:
SCORE_API_URL=http://IP_DO_SCORE:8080
DECISAO_API_URL=http://IP_DA_DECISAO:8081

O CredCasa usa:
Score:   POST /api/v1/score/evaluate
Decisão: POST /api/v1/decisao

IMPORTANTE: o CredCasa NÃO chama Juros diretamente. A Decisão chama Juros e devolve o resultado no campo integracaoJuros.
