TESTE MAIS SIMPLES (WINDOWS)

1. Extraia todo o ZIP para uma pasta.
2. Dê duplo clique em INICIAR_TESTE.cmd.
3. Na primeira vez, aguarde o npm instalar as dependências.
4. Será aberta uma janela chamada "CredCasa - Servidores". Deixe-a aberta.
5. O navegador abrirá em http://localhost:3000/teste-api.html
6. Clique em:
   - "Testar cenário SIM" para percorrer as 5 etapas.
   - "Testar cenário NÃO" para confirmar que a esteira encerra após Decisão.

RESULTADO ESPERADO NO CENÁRIO SIM
PRODUTOS -> SCORE -> DECISAO -> SIMULACAO -> OPERACOES -> ESTEIRA FINALIZADA

RESULTADO ESPERADO NO CENÁRIO NÃO
PRODUTOS -> SCORE -> DECISAO -> ESTEIRA ENCERRADA
Simulação e Operações NÃO devem ser chamadas.

IMPORTANTE
A pasta backend/mocks simula os outros grupos somente para teste local.
Quando os grupos entregarem as APIs reais, troque as URLs no backend/.env.
